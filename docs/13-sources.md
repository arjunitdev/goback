# 13 — Research sources and verification log

**Research date:** 2026-10-28. The following sources were located and are starting evidence, not a completed archive screenshot collection. No historical assets or Wayback snapshots have been downloaded into this package.

1. YouTube official blog, *New Channels, new homepage, new look* (December 2011): https://blog.youtube/news-and-events/new-channels-new-homepage-new-look/ — documents design leading into 2012.
2. Google official Search blog, *Spiffing up your search results page* (November 6, 2012): https://search.googleblog.com/2012/11/spiffing-up-your-search-results-page.html — documents desktop results layout refresh.
3. Meta Newsroom, *Timeline: Now Available Worldwide* (December 2011, January 2012 update): https://about.fb.com/news/2011/12/timeline-now-available-worldwide/ — dates Timeline rollout.
4. Meta Engineering, *Building Timeline* (January 5, 2012): https://engineering.fb.com/2012/01/05/web/building-timeline-scaling-up-to-hold-your-life-story/ — corroborates era and functionality.
5. Chrome Web Store Developer Program Policies: https://developer.chrome.com/docs/webstore/program-policies/policies/ — single-purpose, security, data and IP requirements.
6. Chrome Web Store Impersonation and IP policy: https://developer.chrome.com/docs/webstore/program-policies/impersonation-and-intellectual-property — publisher and trademark risk.
7. Chrome extension content scripts documentation: https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts — verify run_at, isolated world and host permissions at implementation.
8. Chrome Manifest V3 overview: https://developer.chrome.com/docs/extensions/develop/migrate/what-is-mv3 — verify current requirements before release.
9. Internet Archive Wayback Machine: https://web.archive.org/ — intended primary archival exploration portal; actual snapshot inventory pending.
